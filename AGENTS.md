# Daniil Zabolotnyi — Shorts editor landing

Одностраничный лендинг-портфолио видеомонтажёра (Reels, TikTok, YouTube Shorts) для привлечения клиентов. Тексты на странице — английские.

## Команды

| Команда | Что делает |
|---------|------------|
| открыть `index.html` в браузере | Запустить локально. Сборки, зависимостей и `package.json` нет |
| Playwright по `file://…/index.html` на 360 / 390 / 768 / 1024 / 1440 | Проверка: нет горизонтальной прокрутки, ошибок в консоли, цены в одну строку, карточки 9:16. Скрипта в репозитории нет, Playwright ставится вне проекта |

## Где что

- `index.html` — всё: стили в `<style>` (токены на `:root`), скрипт в конце `<body>`.
- Карточка видео — `button.reel[data-src][data-poster]`. Чтобы показать ролик, заполни оба атрибута. Пустой `data-src` — клик ничего не делает.
- Кнопки тарифов — `a[data-package]` → скрытое поле `package` в форме.
- Форма — `form.form`. Пустой `action` показывает «Thanks!» локально. Адрес Formspree вставлять в `action` (там комментарий).
- `screenshots/` — снимки последней проверки.

## Подводные камни

- Факты о Данииле (ник, почта, фото, отзыв, ответ «Do you film…», адрес сайта для `og:url`/`og:image`) — только от него. Сейчас там видимые заглушки `[…]`, не выдумывать.
- `body { overflow-x: hidden }` прячет переполнение: прокрутку проверяй по положению элементов, а не только по `scrollWidth`.
- Битая ссылка на видео даёт в консоли браузерную строку «Failed to load resource». Из JS её не убрать, это не баг страницы.
- Python на этой машине нет.

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Дашборда нет (на машине нет Python) — статусы в `manifest.md`. Требование из `manifest.md` может снять
только пользователь. Прерванную сборку продолжает «продолжи автопилот».
